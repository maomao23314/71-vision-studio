# 任务

在 `docs/改动流水账.md` **末尾追加**一节，记录本轮（第五轮）做了什么。
绝不能改动已有内容 —— 那是四轮积累下来的判断记录。

# 硬性约束

- 编码必须是 UTF-8。★ 用 `Get-Content`/`Set-Content` 处理中文文件会破坏编码
  （本轮踩过：PowerShell 默认按 GBK 读 UTF-8，中文全变乱码，
  `git checkout --` 才救回来）。**一律用 Python 的 `io.open(..., encoding='utf-8')` 读写。**
- 用 `\n` 换行，不要 `\r\n`。
- 只追加，不重排、不删改既有章节。
- 文件末尾可能没有换行符，追加前先检查并补上。

# 写法

```python
import io, os

CHANGELOG = r'docs\改动流水账.md'

SECTION = """<markdown 正文>"""

with io.open(CHANGELOG, 'r', encoding='utf-8') as f:
    old = f.read()

if not old.endswith('\n'):
    old += '\n'

with io.open(CHANGELOG, 'w', encoding='utf-8', newline='\n') as f:
    f.write(old + '\n' + SECTION)
```

# 内容要求

流水账是给**以后的自己**看的，重点不是"改了什么"而是"为什么这么改、踩了什么坑"：

1. **用户提的需求原话**（简短引用）
2. **想清楚的问题**：为什么这么分组？为什么按钮放这个位置？
3. **★ 踩到的坑** —— 尤其是自己写错又发现的地方（比正确记录更有价值）
4. **验证方式**：跑了什么、负向验证做没做
5. **留了什么没做**

# 验收

追加后用 read 工具读回文件末尾，确认：中文正常、没有乱码、历史内容完好。
